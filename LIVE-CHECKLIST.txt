2. VERIFY DEPLOYMENT (10 mins)
   
   a) Check Actions:
      https://github.com/statuteapp/statuteapp.github.io/actions
      → Look for "Build feed" ✅ Success
   
   b) Visit Site:
      https://statuteapp.github.io/
      → Click "Today" tab
      → Should see environmental measures
   
   c) Check Console (F12):
      → No errors
      → Should see: "Loading measures from ./measures.json"
   
   d) Test Crime Pins:
      → Tap a pin
      → Should show "Police street-level crime" label

3. IF SOMETHING BREAKS
   → Check BUGS.md troubleshooting section
   → Review GitHub Actions logs
   → Last resort: See Rollback section below
